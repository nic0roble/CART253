# Frost Night

Nicolas Robledo Sanchez

[View this project online](https://nic0roble.github.io/CART253/finalProject/Frost_Night/)

## Description

My final project is about a farmer who has to cover his sunflowers before the night frost freezes them. The problem is that the covers keep falling off the sunflowers over time, so he has to keep putting them back on until dawn.

My project is based on The Last Lovely Day, an example I found on OpenProcessing
